# Examples

`examples/` contains non-normative, worked examples for people and AI assistants.

Useful examples include:

- an idea submitted through an Issue;
- a multilingual discussion with original text and derived translation;
- a research-record YAML file;
- an accepted proposal and linked decision;
- a compliant AI-assistance disclosure;
- an example that intentionally fails schema validation.

Every example should state which specification or guide it demonstrates and whether it is current.

Examples help interpretation but do not override `specs/`, `governance/` or `decisions/`. AI must not cite an example as a binding rule when the normative source says otherwise.

Do not place real private conversations, credentials, personal data or restricted datasets in examples.
