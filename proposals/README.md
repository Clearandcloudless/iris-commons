# Proposals

`proposals/` contains formal RFC-style proposals that have matured beyond ordinary Issue discussion but are not yet accepted specifications or governance rules.

A proposal should normally originate from an Issue and include:

- problem statement;
- proposed approach;
- alternatives considered;
- risks and trade-offs;
- implementation or validation plan;
- unresolved questions;
- links to the originating Issue and relevant evidence.

Suggested path:

```text
proposals/IRIS-RFC-0001/proposal.md
```

Suggested statuses:

```text
draft · discussing · under-review · accepted · rejected · withdrawn
```

Acceptance of a proposal does not automatically make its text normative. Accepted requirements should be incorporated into `specs/`, `governance/` or `decisions/` through an explicit Pull Request.

Ordinary ideas and questions must begin as Issues rather than files in this directory.
