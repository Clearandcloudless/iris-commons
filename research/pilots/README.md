# Research Pilots

This directory contains active public-interest pilot projects used to test Iris Commons collaboration methods on real, bounded questions.

A pilot must originate from a public Pilot Issue and define:

- public value and beneficiaries;
- scope and deliverables;
- method and validation criteria;
- data sources, licenses and classification;
- privacy, ethics, safety and misuse risks;
- required languages and participant roles;
- human and AI responsibilities;
- completion or stopping conditions.

Restricted or unredacted data must remain outside this public repository.
