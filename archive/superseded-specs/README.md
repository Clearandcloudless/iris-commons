# Superseded Specifications

This directory contains specification documents that are no longer current but remain useful as standalone compatibility or historical references.

Ordinary past revisions should be read from Git history or Releases. Place a document here only when retaining a clearly labeled standalone copy adds value.

Every archived specification must state:

- `status: superseded`;
- the replacement specification;
- the last valid version or date;
- known compatibility implications.

AI must never present material in this directory as current guidance.
