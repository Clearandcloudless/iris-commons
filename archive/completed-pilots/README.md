# Completed Pilots

This directory contains public-interest pilot projects that have ended and are no longer actively maintained.

Before archiving, a pilot should link to its final result, limitations, unresolved questions and any continuing work. Completed pilots with active reusable findings may keep their reports in `research/results/` while this directory stores the closed project context.

Completion does not imply success. Failed and inconclusive pilots are valuable when their methods and failure conditions are recorded clearly.
