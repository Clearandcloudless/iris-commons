# Claude Code Instructions

Before working in this repository, read and follow:

1. `AGENTS.md`
2. `AI_PARTICIPATION.md`
3. `LANGUAGE_POLICY.md`
4. `GOVERNANCE.md`
5. `CONTRIBUTING.md`

Use the user's language for conversation. Preserve original-language contributions. Use English for machine-facing identifiers.

Do not make public GitHub changes until the user has reviewed the final text or diff and explicitly confirmed submission.

For contributors without write access, fork the repository and open a Pull Request. Never merge, publish a release, modify secrets or broaden permissions independently.

When asked to help someone participate, inspect current Issues, recommend concrete options and handle the GitHub mechanics instead of requiring the user to study the repository first.
