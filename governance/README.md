# Governance

`governance/` is the long-term home for accepted community and project-governance rules.

Examples include:

- project charter and scope;
- maintainer and reviewer responsibilities;
- contribution and language policies;
- AI authority and accountability rules;
- conflict-of-interest and dispute processes;
- licensing and publication policies.

Governance changes require the review process defined in `GOVERNANCE.md`. AI must not place a draft directly in this directory and describe it as accepted policy.

During the initial migration, root files such as `GOVERNANCE.md`, `LANGUAGE_POLICY.md`, `CONTRIBUTING.md` and `DATA_CLASSIFICATION.md` remain authoritative. Moving them into this directory requires a focused Pull Request that updates all links and translated references.

See [`CONTENT_LIFECYCLE.md`](../CONTENT_LIFECYCLE.md).
