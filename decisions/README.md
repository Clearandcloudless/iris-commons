# Decisions

`decisions/` records accepted project decisions and the reasoning behind them.

Specifications describe what current implementations should do. Decision records explain why the project chose that direction, which alternatives were considered, what disadvantages remain and when the decision should be revisited.

Suggested naming:

```text
decisions/IRIS-ADR-0001-use-english-machine-identifiers.md
```

A decision record should include:

- context and problem;
- decision;
- alternatives considered;
- rationale;
- consequences and known disadvantages;
- status and approval information;
- related Issues, proposals, specifications and research;
- conditions that would justify reconsideration.

Draft decisions belong in Issues or `proposals/`. Only accepted decisions should be placed here.
